# GCS Threat Report Template

## Instructions

- Clone the repository
- Edit the report.md file with the content
    - Adjust authors, TLP, TLP color, Color, Case ID
- Place additional files, such as images in the `resources` folder
- Compile using `build.sh`. You may need to run it as `sudo`

```
$ sudo bash ./build.sh
```

A PDF report should be available



## Requirements

This will require `docker`
